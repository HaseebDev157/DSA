# DSA
📚 Data Structures and Algorithms in Java

This repository contains my Data Structures and Algorithms (DSA) practice and assignment work implemented in Java.

The main purpose of this repository is to understand the fundamentals of data structures by implementing their operations from scratch using arrays and basic Java programming concepts.

🚀 Topics Covered

1. Array

The Array implementation demonstrates common array operations through a menu-driven Java program.

Operations included:

- ➕ Add an element
- 📍 Insert an element at a specific index
- 📝 Fill the array
- ❌ Delete the last element
- 🗑️ Delete an element by index
- 👀 Display elements
- 🔎 Search for an element
- 📌 Access an element by index
- ✏️ Update/replace an element
- 📏 Check array size

The array uses a fixed maximum capacity of 100 elements.

2. Stack

The Stack implementation uses an array and follows the LIFO (Last In, First Out) principle.

Operations included:

- "Push" — Add an element
- "Pop" — Remove the top element
- "Display" — Show stack elements
- "Size" — Check current size
- "isEmpty" — Check whether the stack is empty
- "isFull" — Check whether the stack is full

The implementation also handles Stack Overflow and Stack Underflow conditions.

3. Queue

The Queue implementation uses an array and follows the FIFO (First In, First Out) principle.

Operations included:

- "Enqueue" — Add an element to the rear
- "Dequeue" — Remove an element from the front
- "Display" — Show queue elements
- "Size" — Check current size
- "isEmpty" — Check whether the queue is empty
- "isFull" — Check whether the queue is full

The queue is implemented as a circular queue, allowing the front and rear positions to wrap around the array.
